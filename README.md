# Dulce Balance Repostería

Aplicación web mobile-first para calcular costos de productos de repostería artesanal. El proyecto se construye por fases; las fórmulas y decisiones del producto están documentadas en [CLAUDE.md](CLAUDE.md).

## Requisitos

- Node.js 22 o superior
- npm

## Desarrollo local

```bash
npm install
npm run dev
```

## Validación de producción

```bash
npm run build
npm run preview
```

La base actual utiliza Vite, React, TypeScript y Tailwind CSS. La lógica de cálculo, las pruebas, la persistencia local y las capacidades PWA se incorporarán en sus fases correspondientes.
